# Alp Inangu's website

The website is in the website folder. Open `index.html` in a browser, or upload the contents of the website folder to a static web host such as GitHub Pages.

- Edit `index.html` to add your biography, portrait, research, and projects. HTML comments mark the insertion points; they are not displayed to visitors.
- Edit `stylesheet.css` to adjust the existing template styling.
- Replace `data/CV_Inangu.pdf` to update your CV, keeping the filename unchanged.

Only your name, CV, LinkedIn, and GitHub are currently displayed. No biography, photo, or achievements have been invented.
